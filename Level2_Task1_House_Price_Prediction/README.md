## Level 2 – Task 1: Predicting House Prices with Linear Regression

### Objective

Built a Linear Regression model to predict house prices using relevant
property features.

### Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

### Key Steps

- Exploratory Data Analysis
- Missing value handling
- Feature selection
- One-Hot Encoding of categorical features
- Correlation analysis
- Train/Test Split (80/20)
- Linear Regression
- Model Evaluation using MSE, RMSE and R²
- Actual vs Predicted Price visualization
- Residual analysis
- Coefficient analysis

### Model Evaluation

The Linear Regression model was evaluated using:

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

### Outcome

The project demonstrates an end-to-end machine learning workflow for
house price prediction, from data preprocessing and exploratory analysis
to model training, evaluation and interpretation.
